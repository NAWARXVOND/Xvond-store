# Store Assets

Put storefront images in this folder so they are easy to reference from the frontend.

Recommended names:
- `logo.png`
- `hero.png`
- `categories/<category>.jpg`
- `products/<product-slug>.jpg`

Files under `frontend/public/assets/` are served from `/assets/...` (or `${NEXT_PUBLIC_BASE_PATH}/assets/...` when the store runs under `/store`).
